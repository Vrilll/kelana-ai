# KelanaAI

AI Travel Planner built with Python, Next.js & Amazon Bedrock.

## Tugas Sesi 1 — Trip Summary Generator (Console App)

Console app that collects trip details from the user and prints a formatted
trip summary.

### Project Structure

```
kelana-ai/
├── README.md
├── backend/
│   └── main.py
└── frontend/
    └── .gitkeep
```

### How to Run

```bash
cd backend
python3 main.py
```

You will be prompted for:
- `destination` (string)
- `country` (string)
- `days` (integer)
- `budget` (float)
- `currency` (string)
- `travel_month` (string)

### Example Output

```
========================
KelanaAI
========================
Destination : Japan
Country   : Japan
Days     : 5
Budget    : 1500 USD
Currency   : USD
Travel Month : December
```
